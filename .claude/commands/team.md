---
description: Показать шпаргалку по агентам проекта — кто есть, что делает, как позвать
allowed-tools: Read, Glob, Grep
---

Прочитай все файлы .claude/agents/*.md в проекте. Для каждого агента выведи компактную шпаргалку:

| Агент | Назначение | Пример запроса | Использует skills |
|---|---|---|---|

- Назначение — из description файла агента, одной строкой.
- Пример запроса — придумай реалистичную фразу пользователя под этого агента.
- Использует skills — если в теле агента упомянуты skills проекта (.claude/skills/*), перечисли; иначе «—».

В конце добавь одну строку: «Создать нового агента: просто опиши процесс словами — meta-agent сделает файл».
